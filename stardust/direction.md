# Direction — Pebl (hellopebl.com) presales uplift

Brand surface (Mode A — pinned):
- Palette: Arctic teal `#04404e`, Pacific mint `#6bdacd`, Text near-black `#171717`, white `#fff`, warm sand stroke `hsla(40,12%,80%,.33)`.
- Type: FK Roman Standard (display serif, 700) for headings; Sharp Earth (body); Inter as fallback.
- Motifs: 20px rounded pills (CTAs/chips), warm human photography, logo wall, card grids.
- Voice: confident, lightly playful ("Build teams anywhere. Yes, even there.").
- Register: brand (marketing landing).

## Variant A — Faithful + improvements

Role: risk-averse green-light. "Yes, that's us, with the obvious fixes."
Composition: same IA as captured (hero → trust strip → end-to-end HR → meet Pebl → G2/compliance → 24-hour hire → competition → insights → FAQs → footer).
Motion: static (no cinematic layer).
Improvements applied:
1. Give the hero headline room — single confident hero, primary + ghost CTA, supporting visual restrained.
2. De-duplicate "Meet Pebl"; establish clear section hierarchy (one hero-weight, the rest supporting).
3. Promote the logo trust strip to directly under the hero.
4. Add a dedicated metric band: 185+ countries · 24-hour hire · #1 on G2.
5. Tighten vertical rhythm (cap section padding ≤ 96px desktop), let the serif + palette carry brand.

## Variant B — What if Arctic teal anchored the page and the serif became its spine?

Role: design-team motivator. The brand's underused capability foregrounded.
What if: "What if Pebl read like a premium editorial publication — deep Arctic frame, FK Roman serif as structure — instead of a white SaaS template?"
Captured trait amplified: Color-ladder re-weighting (#04404e as ground) + Display-typography as spine.
Evidence: brand palette is arctic+pacific but deployed as accent-on-white; FK Roman 700 at 52–85px already on every heading.
Composition: dark Arctic-teal editorial sections alternating with mint/cream; oversized serif section openers as numbered editorial chapters; the logo wall set as a confident credibility band on teal; metric band in pacific mint. Same content/IA as A, recomposed.
Motion: static (no cinematic layer).

## Variant C — What if motion was part of the identity?

Role: visionary pitch. The brand's third dimension — kinetic.
What if: "What if the FK Roman serif headline assembled itself — words arriving line-by-line as you scroll — so the type IS the experience?"
Cinematic register: kinetic-display (auto-picked from brand personality: confident, type-forward, editorial).
Captured trait amplified: Display-typography amplification (the candidate kinetic-display naturally amplifies through motion).
Evidence: marquee FK Roman serif headlines; confident voice beats.
Composition: identical IA to A; the bet is motion, not layout.
Motion: cinematic, register kinetic-display — scroll-driven line/word reveals on serif headers, a pinned hero where the headline resolves, mint underline draws, metric count-ups. Full prefers-reduced-motion neutralization.
